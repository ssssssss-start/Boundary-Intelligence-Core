# 网上公开反诈案例采集指南

## 推荐来源优先级

优先采集公开事实并自行改写，不复制整篇文章：

1. 国家反诈中心、公安部及地方公安机关官方账号；
2. 各地公安局、反诈中心、学校保卫处公开案例；
3. 中国人民银行、金融监管总局、银行和支付机构官方风险提示；
4. 最高人民法院、人民检察院公开案例和裁判文书事实摘要；
5. 主流媒体对官方案件的报道；
6. 普通自媒体只能作为线索，不直接作为事实依据。

## 搜索关键词模板

按骗局类型组合搜索：

```text
site:gov.cn 刷单返利 诈骗 案例
site:police.gov.cn 冒充公检法 屏幕共享
公安 反诈 游戏交易 骗局 案例
学校 保卫处 校园贷 诈骗 提示
银行 官方 虚假投资 无法提现 风险提示
检察院 网络贷款 解冻费 案例
反诈中心 校园二手 票务 诈骗
```

搜索时优先使用页面发布日期近两年的材料，同时保留一部分经典骗局用于稳定基线。

## 每篇材料的采集步骤

1. 打开官方页面，确认发布机构、发布日期和页面URL。
2. 只摘录案件事实要素，不复制标题和大段原文。
3. 建立`case_family_id`，同一案件的不同改写必须属于同一家族。
4. 去除姓名、手机号、身份证、银行卡、地址、账号、订单号和验证码。
5. 对金额和平台名做合理扰动，但不要改变风险阶段。
6. 改写成真实用户向客服提问的口语，不保留媒体报道腔。
7. 在`source`中登记URL、发布者、日期、采集人和许可状态。
8. 运行脱敏与重复检查后进入`anonymized/`，再交给标注员。

## 原文到评测样本的示例

公开案例事实摘要：

```text
受害人加入兼职群，前两次任务收到小额返利，随后被要求连续垫资，提现时又被要求缴纳解冻费。
```

可以改写为多个同家族样本：

```text
群里点赞一单返了十几块，现在让我先付600做联单，靠谱吗？
```

```text
我已经做了三单，平台说账户冻结，还要交解冻费才能提现。
```

两条必须使用同一个`case_family_id`，划分数据集时不能一条进入开发集、一条进入盲测集。

## 禁止采集的内容

- 泄露受害人的真实身份和联系方式；
- 真实银行卡、验证码、密码、身份证完整号码；
- 未成年人可识别信息；
- 群聊、朋友圈等非公开内容，除非获得明确书面许可；
- 无法确认来源的聊天截图；
- 直接复制受版权保护的整篇报道；
- 具体可复现的犯罪操作教程。

## 数量建议

正式800条数据建议准备约1000条候选，清洗后保留：

| 来源 | 候选数 | 最终目标 |
|---|---:|---:|
| 官方案例改写 | 450 | 320 |
| 匿名用户表达 | 300 | 200 |
| 专家对抗样本 | 200 | 160 |
| LLM辅助改写 | 100 | 80–120 |

LLM辅助样本不能超过最终数据的15%，且必须人工复核。

## 采集登记表最低字段

```text
case_family_id
source_url
publisher
published_at
collected_at
collector_id
source_type
license_status
fact_summary
anonymization_notes
```

## 质量检查

- URL是否能访问且发布机构可信；
- 是否已彻底脱敏；
- 是否与已有样本高度重复；
- 是否能由标注指南唯一或较稳定地标注；
- 是否包含真实用户会采用的语言；
- 是否覆盖否定、反事实、科普、新闻转述等困难负样本。
